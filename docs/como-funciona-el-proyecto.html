1. ¿Qué es este proyecto?

Es una página web estática (sin servidor ni base de datos) que funciona sólo con HTML + CSS + JavaScript. Es un "regalo digital" para Yanet: cuenta la historia de la pareja con fotos, frases, un álbum animado, un carrusel de momentos y un quiz interactivo. Al ser estática, se puede abrir en cualquier navegador sin instalar nada o publicar gratis en GitHub Pages / Netlify.

5. Sistema de estilos (CSS)

CSS/main.css no define estilos: sólo importa los demás archivos con @import. Cada sección de la página tiene su propia hoja, lo que mantiene el proyecto ordenado.

  • Fondo global: tres capas degradadas (radiales rojo/azul + lineal) en general.css.
  • Hero: imagen de fondo en 100vh con capa oscura (.overlay) para el texto.
  • Efecto de libro: la portada gira con rotateY(-160deg) usando perspective en album.css.
  • Carrusel infinito: animación scrollGallery de translateX(0) a translateX(-50%) en moments.css. Como los momentos están duplicados, el recorrido del 50% "se cierra" y parece infinito.
  • Responsive: cada hoja incluye @media (max-width: 768px) para ajustar tamaños en celular.

6. Cómo ver el proyecto

  1. Abrir Index.html directamente con doble clic (o arrastrarlo al navegador). Funciona sin instalar nada.
  2. Para usarlo como sitio web público, se puede subir el repositorio a GitHub Pages o Netlify.
Importante (rutas): los servidores Linux (GitHub Pages, Netlify) distinguen mayúsculas de minúsculas. Por eso todos los enlaces usan exactamente CSS/, JS/ y Assets/Images/ (con mayúsculas). En Windows funciona de ambas formas, pero en internet debe coincidir al 100%.

8. Qué más puedes mejorar

  • Botón de pausar/mutar la música: hoy la canción inicia al abrir el quiz y no hay forma de detenerla.
  • Elegir frases sin repetir: phrases.js elige con Math.random(), a veces se repite la misma frase seguido. Se podría barajar el arreglo.
  • Activar la animación al cargar: en scroll.js, las tarjetas ya visibles al abrir podrían mostrarse de inmediato llamando una vez a la función.
  • Texto alternativo (alt) en las fotos para mejorar la accesibilidad.
  • Favicon (icono de la pestaña).
  • Comprobar las fechas de la línea de tiempo (ejemplo) que dicen 2024, cuando la historia inició en septiembre de 2025.
