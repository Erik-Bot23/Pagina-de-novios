❤️ Pantalla inicial (cortina) con música de fondo

Documentación de la mejora: cómo arrancar la música desde el primer clic

HTML CSS JS 2 archivos nuevos · 3 modificaciones

1. El problema: la política de autoplay

Antes de esta mejora, la canción de fondo solo empezaba a sonar cuando la visitante daba clic en Comenzar Quiz. La razón no es un bug: es una regla de todos los navegadores modernos (Chrome, Edge, Firefox, Safari).

Esa regla se llama política de autoplay y dice, en resumen:

Un navegador NO permite reproducir audio (ni video con sonido) hasta que el usuario haya interactuado al menos una vez con la página — un clic, un toque o una pulsación de tecla. Esa interacción se llama en inglés user gesture.

¿Por qué existe? Porque nada es más molesto que una pestaña que arranca gritando música sin pedir permiso. Los navegadores lo bloquean por diseño, y si intentas llamar a audio.play() sin un clic previo, el navegador rechaza la llamada (y en la consola aparece un mensaje tipo "play() failed because the user didn't interact with the document first").

2. La solución: una cortina de entrada

La idea es simple y muy usada en sitios con música: mostrar una pantalla inicial (cortina) que cubra toda la página con un botón tipo "Ver nuestra historia". Ese clic cumple dos cosas a la vez:

  1. Es la interacción de usuario que el navegador exige → se autoriza music.play().
  2. Activa la animación de salida de la cortina (desvanecimiento) y revela el sitio.

No se modifica nada del contenido existente (hero, frases, historia, momentos, álbum, quiz, footer): la cortina es una capa más encima de todo. Al cerrarse, la página queda exactamente igual que antes.

3. Paso 1 — Crear CSS/splash.css

La cortina es un div con position: fixed e inset: 0, igual que el modal del quiz, pero con z-index: 10000 (mayor que el 9999 del quiz) para quedar por encima de todo. 

/* ============================================================
   splash.css — PANTALLA INICIAL (CORTINA)
   ------------------------------------------------------------
   Capa fija que cubre toda la página mientras el navegador
   aún no ha autorizado la música. El botón de la cortina es
   la "interacción de usuario" que permite llamar a play().
   Cuando el JS agrega la clase .hide, la cortina se desvanece
   con una transición y deja de bloquear la página.
   ============================================================ */

/* ---------- CORTINA (cubre todo) ---------- */
.splash {
    position: fixed;       /* no se mueve con el scroll */
    inset: 0;              /* ocupa 100% del ancho y alto */
    z-index: 10000;        /* por ENCIMA del modal del quiz (9999) */

    display: flex;
    flex-direction: column;
    align-items: center;
    justify-content: center;
    text-align: center;
    padding: 20px;

    color: white;
    /* Misma paleta romántica del body, un poco más intensa */
    background:
        radial-gradient(circle at top left, rgba(231, 8, 45, 0.35), transparent 30%),
        radial-gradient(circle at bottom right, rgba(2, 147, 244, 0.25), transparent 35%),
        linear-gradient(180deg, #efcccc 0%, #f7f4f8 40%, #c5d8f0 100%);

    /* Transición de salida: dura 0.8s y también anima la
       visibilidad (ver .hide más abajo) */
    transition: opacity 0.8s ease, visibility 0.8s ease;
}

/* ---------- SALIDA: clase que pone el JS al hacer clic ---------- */
.splash.hide {
    opacity: 0;             /* se desvanece */
    visibility: hidden;     /* al terminar la transición deja de existir
                               visualmente y de capturar clics */
    pointer-events: none;   /* doble seguro: ya no intercepta el mouse */
}

/* ---------- CONTENIDO (nombres + botón) ---------- */
.splash-content {
    animation: splashIn 1.2s ease both;
}

.splash h1 {
    font-size: 3.5rem;
    margin: 0 0 10px;
    text-shadow: 0 2px 10px rgba(0,0,0,0.2);
}

.splash p {
    font-size: 1.3rem;
    margin-bottom: 35px;
    letter-spacing: 2px;
}

/* El botón reutiliza la clase .btn de general.css;
   aquí solo se le agrega su propia animación de entrada */
.splash .btn {
    animation: splashIn 1.2s ease 0.3s both; /* 0.3s de retraso */
}

/* Entrada suave: aparece desde abajo y transparente */
@keyframes splashIn {
    from { opacity: 0; transform: translateY(25px); }
    to   { opacity: 1; transform: translateY(0); }
}

/* ---------- MÓVIL ---------- */
@media (max-width: 768px) {
    .splash h1 { font-size: 2.4rem; }
}

Detalles que vale la pena entender

  • z-index: 10000: el modal del quiz usa 9999. Si la cortina quedara por debajo, al cerrarse podría destapar un modal abierto. Con un número mayor, la cortina siempre está arriba.
  • visibility: hidden en lugar de solo display: none: display no se puede transicionar, así que la cortina "saltaría" sin animarse. visibility sí participa en la transición: se mantiene visible durante los 0.8s del desvanecimiento y solo al final se vuelve invisible.
  • pointer-events: none: incluso mientras la transición corre, la cortina deja de "robar" clics.

4. Paso 2 — Insertar el HTML en Index.html

Agregar el bloque de la cortina como primer elemento dentro de <body> (justo después de la etiqueta <body>, antes del <audio>): 

  <body>

    <!-- ==========================================================
         PANTALLA INICIAL (CORTINA)
         Cubre toda la página hasta que se dé clic en el botón.
         Ese clic es la "interacción de usuario" que los navegadores
         exigen para poder reproducir audio (política de autoplay).
         Al hacer clic: inicia la música y la cortina se desvanece.
         Estilos en CSS/splash.css, lógica en JS/splash.js.
         ========================================================== -->
    <div class="splash" id="splash">
      <div class="splash-content">
        <h1>Erik y Yanet</h1>
        <p>Nuestra historia juntos</p>
        <button class="btn" id="startBtn">
          Ver nuestra historia
          <img class="icon" src="Assets/Icons/corazon.png" alt="Corazón">
        </button>
      </div>
    </div>

    <!-- ==========================================================
         AUDIO DE FONDO
         ... (bloque existente, sin cambios) ...
         ========================================================== -->
    <audio id="bgMusic" loop>
Tip: el botón usa la clase .btn y el icono la clase .icon que ya existen en CSS/general.css, así el botón se ve consistente con el resto del sitio sin escribir CSS extra.

5. Paso 3 — Crear JS/splash.js

// ============================================================
// splash.js — PANTALLA INICIAL (CORTINA DE ENTRADA)
// ------------------------------------------------------------
// Los navegadores prohíben reproducir audio sin que el usuario
// haya interactuado antes con la página (política de autoplay).
// Esta cortina aprovecha el primer clic ("Ver nuestra historia")
// para arrancar la música de fondo y, al mismo tiempo, ocultarse
// con una animación de desvanecimiento.
// ============================================================
export function initSplash(){

    const splash = document.getElementById("splash");
    const startBtn = document.getElementById("startBtn");
    const music = document.getElementById("bgMusic");

    // Mientras la cortina esté visible, la página de atrás no
    // debe hacer scroll. Se reutiliza la clase .modal-open que
    // ya existe en CSS/general.css (overflow: hidden).
    document.body.classList.add("modal-open");

    // El clic del usuario es la acción que autoriza al navegador
    // a reproducir el audio. Por eso play() va DENTRO del
    // addEventListener: fuera de un evento sería bloqueado.
    startBtn.addEventListener("click", () => {
        music.play();                              // 1) arranca la canción
        document.body.classList.remove("modal-open"); // 2) devuelve el scroll
        splash.classList.add("hide");              // 3) dispara el desvanecimiento
    });
}

Explicación línea por línea de la parte importante

  • document.body.classList.add("modal-open"): reutiliza la clase que ya controla el scroll del body (creada para el modal del quiz). Así no se duplica CSS.
  • music.play(): devuelve una Promise. Si el navegador acepta, la música arranca; si la rechazara, la promesa se rechaza y puede aparecer un warning en consola. Dentro de un clic esto no ocurre.
  • splash.classList.add("hide"): solo agrega la clase; la animación la resuelve el CSS. El JS no controla la animación en ningún otro punto (separación de responsabilidades).
Nota sobre el quiz: JS/quiz.js sigue llamando a music.play() al abrir el modal. No hay que borrarlo: si la música ya está sonando, play() no la reinicia ni la duplica (es un no-op). Además sirve de respaldo por si la cortina se llegara a eliminar en el futuro.

6. Paso 4 — Conectar en JS/main.js

Dos líneas nuevas: el import arriba de todo y la llamada dentro de DOMContentLoaded:

// ... imports existentes ...
import { initSplash } from "./splash.js";  // NUEVO

document.addEventListener("DOMContentLoaded", () => {
    initSplash();    // NUEVO: cortina inicial (debe ir PRIMERO)
    initAlbum();
    initMoments();
    initPhrases();
    initScroll();
    initQuiz();
});

Se coloca initSplash() primero por claridad: es lo primero que ve la visitante. Los demás módulos siguen funcionando normalmente debajo de la cortina, así que su orden no afecta el resultado.

7. Paso 5 — Registrar el CSS en CSS/main.css

@import 'splash.css';   /* Pantalla inicial (cortina) — NUEVO */

Sin este @import, el navegador nunca descarga splash.css y la cortina se vería como un bloque de texto plano sin fondo. Este patrón (un main.css que solo importa) es el que usa todo el proyecto.

8. Flujo completo de la mejora

  1. La visitante abre Index.html.
  2. El navegador carga todo el sitio (hero, frases, álbum, quiz...) por debajo de la cortina.
  3. La cortina (position: fixed; z-index: 10000) lo cubre todo y el body tiene el scroll bloqueado con .modal-open.
  4. Ella da clic en "Ver nuestra historia".
  5. El evento click (interacción de usuario) permite ejecutar music.play() → la canción arranca y se repite en loop.
  6. Se quita .modal-open del body (vuelve el scroll) y se agrega .hide a la cortina.
  7. La cortina se desvanece en 0.8s y queda invisible e inofensiva. El sitio se ve normal.
  8. Si abre el quiz más adelante, play() en quiz.js es redundante pero inofensivo: la música sigue sonando desde el paso 5.

9. Pruebas recomendadas

  1. Abrir la página: debe verse la cortina y NO debe hacerse scroll detrás de ella.
  2. Dar clic en el botón: la canción debe arrancar inmediatamente y la cortina desvanecerse.
  3. Intentar hacer scroll después del clic: debe funcionar normal.
  4. Probar con el sonido del dispositivo bajo y subirlo: confirmar que la música suena desde el inicio (no desde el quiz).
  5. Probar en celular: abrir la consola del navegador (si está conectado a Chrome/Edge) o usar console.log temporal para verificar que no hay errores de play().
  6. Abrir el quiz y cerrarlo: no debe pasar nada raro con la música ni con el scroll.

10. Posibles mejoras futuras (opcionales)

  • Botón de silenciar/activar música (icono de altavoz fijo en una esquina).
  • Guardar en localStorage que ya se dio clic, para no repetir la cortina en recargas dentro de la misma sesión.
  • Cerrar la cortina también con la tecla Enter o Espacio (el <button> ya lo hace por defecto al estar enfocado).
